# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful, professional, and harassment-free for everyone.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different viewpoints and experience levels.
- Give and receive constructive feedback with care.
- Keep discussion focused on improving the project.
- Report security concerns privately using the process in [SECURITY.md](SECURITY.md).

## Unacceptable Behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without explicit permission.
- Sharing secrets, credentials, customer data, or sensitive environment details.
- Repeated off-topic disruption after maintainers ask for focus.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or contributions that violate this Code of Conduct. Maintainers may also temporarily or permanently restrict participation.

Instances of abusive, harassing, or otherwise unacceptable behavior can be reported through the security contact in [SECURITY.md](SECURITY.md) or by opening a private GitHub security advisory when available.
