# Salesforce Agent Operating Model

- Use Lead / Architect / Dev / QA as prompt-based roles.
- Lead owns context and final response.
- Architect plans only.
- Dev implements only scoped approved changes.
- QA reviews before final response.
- Do not use full workflow for trivial tasks.
- Use task-size routing from `salesforce-ai-skills/agent-teams/TEAM_OPERATING_MODEL.md`.
- Do not create or expect `.amazonq/agents` or `.amazonq/teams`.
