- Read `salesforce-ai-skills/skills/salesforce-global-development/SKILL.md` for Salesforce implementation/review tasks.
- Read only task-specific `SKILL.md` files that apply.

- For Apex/LWC/Flow/metadata/deployment/permissions/data tasks, select only matching skills.
- If unsure, state assumptions and ask for clarification only when blocking.
